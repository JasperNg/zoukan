# Security Policy

## Supported Versions

Security fixes are released for the latest desktop version of Zoukan on Windows (x64) and macOS (Apple Silicon).

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately through [GitHub Security Advisories](https://github.com/JasperNg/zoukan/security/advisories/new). Include:

- A description of the issue and its impact
- Steps to reproduce or a proof of concept
- Affected Zoukan version and OS

## Scope and Threat Model

Zoukan's security boundaries, controls, and accepted risks (including the extension execution model, update verification, encrypted local storage, and embedded browser isolation) are documented in [desktop/THREAT-MODEL.md](desktop/THREAT-MODEL.md).

Issues in third-party extensions should be reported to the respective extension's repository.
