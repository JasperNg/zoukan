# Backup fixtures

Every `.tachibk` (or `.proto.gz`) file in this folder is restored into an empty desktop profile,
backed up again and compared field by field by `BackupRoundTripTest`. The synthetic full-field
backups are generated by the test itself (`SyntheticBackup`); the files here are real exports.

| File | Made by | Contents |
|---|---|---|
| komikku-real.tachibk | Komikku 1.14.1 (Android 15 emulator), every option | 12 entries (MangaDex, MangaPill, a merged entry), 2 categories, history, bookmarks, custom info, saved search, feed, Keiyoushi store, app and MangaDex settings |
| komikku-empty.tachibk | Komikku 1.14.1, fresh install | 3 app settings |
